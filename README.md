A C# .NET Core application for managing hotel operations, including full CRUD functionality for bookings, guests, invoices, and rooms.

## 🚀 Getting started

The application is designed to be plug-and-play. The database and necessary tables are automatically generated upon the first launch
<img width="253" height="136" alt="tablesSSMS" src="https://github.com/user-attachments/assets/c84182c8-7101-4284-ba05-1d90eb532824" />
### Requirements

* **Visual Studio 2022**
* **SQL Server Management Studio (SSMS)** (for viewing data)
* **.NET 10.0 SDK**
 
 ### Setup & Usage
1. Download zip
     ---> https://github.com/jenn-html/HotelApp1/archive/refs/heads/master.zip
2. Extract all files
3. **Open** `HotelApp1.sln` in Visual Studio.
instance.
4. **Run the app:** Press `F5`. The application will automatically create the database and tables for you.
   

### Database 
To handle bookings and guest data, you need to download **SQL Server Management Studio (SSMS)**

1. Go to Folder --> Database 
2. Open file --> syntax.sql  *Now you have SQL syntaxes to easy access information in database!* 
3. Open **SSMS** and connect to your local server.


## 🛠 Features
* **Guest Management:** Full CRUD for guest records.
* **Booking System:** Create, read, update and delete room reservations.
* **Invoicing:** Manage billing and payment status.
* **Room Overview:** Full CRUD for Rooms. Track room availability and details.
